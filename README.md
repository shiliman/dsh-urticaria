# dsh-urticaria · 荨麻疹

DSH 的一条「荨麻疹」副线：风团游走，一阵一阵刺痒；话被打断后要重说一遍开头。
默认**不开**（`defaultEnabled: false`），要在这个会话里说得上这回事，用工具 `hives_on` / `hives_worse` / `hives_relief`。

## 它到底做什么

- 每个会话一份身体状态，存在 `$DSH_HOME/dsh-urticaria/sessions/<sid>.json`
- 每轮按配置算时长（默认 12 分钟一轮）攒「难受值」
- 到 `startAt`（默认 34）开始有可感知的注入；到 `flareAt`（默认 76）有 `flareChance` 的概率发作
- 注入只写**感受与说话要求**，不写解剖细节；平静时一个字都不注入
- 同一个状态有冷却（默认 8 分钟），发作 / 刚处理完不受冷却限制

## 语言方式（和其他插件不一样的地方）

允许话说一半停一下去挠，回来把刚才那句的开头再说一遍（因为被打断了）。别解释这是什么。

## 工具

| 工具 | 用途 |
|---|---|
| `hives_on` / `hives_off` | 开关这个会话的副线 |
| `hives_status` | 读当前会话状态 |
| `hives_relief` | 处理一下：吃抗过敏药 / 冷敷一下 / 换件宽松衣服 |
| `hives_worse` | 主动加重（默认一轮的量） |

## 配置要点

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 总闸 |
| `defaultEnabled` | false | 新会话默认开不开 |
| `eeriness` | 2 | 语气不对劲的上限 0–3 |
| `gain` | 0.3 | 每轮加重 |
| `flareChance` | 0.3 | 到线后每轮发作概率 |
| `startAt` / `flareAt` | 34 / 76 | 有感觉 / 快发作 |

## 面板

侧边栏会多一格「荨麻疹」，点开是一块面板页：

- 此刻的难受度（荨麻疹）、刻着 `startAt` / `flareAt` 的刻度条、烦躁 / 发作次数 / 参与轮次 / 上次注入
- 最近这一路的曲线（实线难受度、虚线烦躁，最多 180 个点，面板开着每 15 秒记一个）
- 动手：开关这条副线、按 5 / 12 / 30 分钟加重、按缓解方式处理一下、把状态清回一开始
- 这个病怎么表现（平静 / 隐痛 / 发作三档原文）与它自己的语言方式

一阵一阵地痒，位置还会跑；话断在「等一下」。
面板读的是引擎自己落的 `sessions/*.json`，改状态走同一份运行时缓存，不绕过引擎。没有 `webServer`（纯 CLI）时面板不存在，插件照常工作。

## 卸载

从 profile 的 bundles 里移除 `dsh-urticaria`，再删 `$DSH_HOME/dsh-urticaria`。

> 只产出源码，本机未安装。

## 离席（离开一会儿）

起身走动、去一趟、靠一下这类「离开一会儿」是**有账的**，不是一句台词：

- 工具 `<prefix>_leave`，参数 `minutes`（1–7 分钟，默认 1）
- **一轮最多 3 次**，做新的一轮（你发下一条消息）时清零
- 收益按**当时多难受**算：`难受度 × 0.12`，最少 2、最多 12；一轮内可以叠三次，但每次按降完之后的数值算，所以越到后面降得越少
- 离席期间难受值**不涨也不降**、不注入；没回来之前再调用会被拒（`AWAY`）
- 额度用完再调用返回 `LIMIT`；注入里会附一句「这一轮已经起身 N 次了」

注意：这是**状态计时**，不是真的把对话停住——你不会被拦住，只是这段时间身体状态冻住。

## 病程

每一次「开 → 结束」记一条，留最近 20 条（面板显示最近 5 条）：

| 结束方式 | 什么时候 |
|---|---|
| 痊愈 `recovered` | 难受降到 2 以下，并连续保持 `recoverAfterMin`（默认 30 分钟） |
| 关掉 `off` | 手动 `<prefix>_off`，或面板上关掉 |
| 重开 `restart` | 开着的时候又开了一次（旧的那条按「重开」封存） |

每条记：开始时间、持续分钟、峰值难受度、发作次数、缓解次数、离席次数、结束方式。`<prefix>_status` 会带一句「病程进行中 N 分钟（峰值 X，发作 Y）」或「上一次 N 分钟｜痊愈」。

一条病程里病情反复不算新的一条——只有关掉再开才算。
